LibreLeaf

v0.0.1 alpha

The LaTeX word processor for independent researchers

LibreLeaf will be a free, open-source LaTeX editor that you use like a word processor. The editor isn't built yet. This first release is its word counter, which follows the same rules as TeXCount.

Your file stays on your computer. Counting happens in this page, and nothing is uploaded.

How words are counted

      
    
        
  • Only the document body counts, plus the \title.
    • 
        
  • Running text, headings and float captions are counted separately. Their total is the sum.
    • 
        
  • Maths counts as items (inline and displayed), not words.
    • 
        
  • Citations, references, labels, URLs, package setup and macro definitions are skipped. Link text in \href counts.
    • 
        
  • Verbatim, code listings, TikZ pictures, comments and the bibliography are skipped.
    • 
        
  • Footnotes count as text. The abstract counts as text and is also shown on its own.
    • 
        
  • Accents stay inside words, so Erd\H{o}s is one word.
    • 
      

      
Small differences from TeXCount are possible with unusual macros. Please report them on GitHub.

    

    

      
Use it from the command line

      
Needs Node.js 18 or newer. It follows \input and \include.


node packages/texcount/texcount.js main.tex
node packages/texcount/texcount.js main.tex --json
