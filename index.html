LibreLeaf

v0.0.2 alpha

The LaTeX word processor for independent researchers

LibreLeaf will be a free, open-source LaTeX editor that you use like a word processor. The editor isn't built yet. These first releases are its word counter, which follows the same rules as TeXCount.

Your file stays on your computer. Counting happens in this page, and nothing is uploaded.

How words are counted

      
    
        
  • Only the document body counts, plus the \title.
    • 
        
  • Running text, headings, and captions and footnotes are counted separately. Their total is the sum.
    • 
        
  • Maths counts as items (inline and displayed), not words.
    • 
        
  • Citations, references, labels, URLs, package setup and macro definitions are skipped. Link text in \href counts.
    • 
        
  • Verbatim, code listings, TikZ pictures, tables made with tabular, comments and the bibliography are skipped. In figures and tables, only the caption counts.
    • 
        
  • The abstract counts as text and is also shown on its own. You can leave it, or the captions and footnotes, out of the sum.
    • 
        
  • Lines between %TC:ignore and %TC:endignore are skipped, as in TeXCount. To count one part only, select it in the box.
    • 
        
  • For a project with several files, open the folder or a .zip (an Overleaf download works). LibreLeaf finds the main file and follows \input, \include and \import.
    • 
        
  • Accents stay inside words, so Erd\H{o}s is one word.
    • 
      

      
On 23 recent arXiv papers, 19 counts were within 1% of TeXCount's. The rest differ for known reasons. If your count looks wrong, please report it on GitHub.

    

    

      
Use it from the command line

      
Needs Node.js 18 or newer. Give it the main file or the project folder.


node packages/texcount/texcount.js main.tex
node packages/texcount/texcount.js my-paper/ --no-abstract
node packages/texcount/texcount.js main.tex --json
